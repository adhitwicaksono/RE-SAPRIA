# Other Genomes

**Status: OPTIONAL TRAINING SPACE — OUTSIDE RE-SAPRIA ANALYSIS**

This directory is reserved for genome-analysis exercises using organisms other
than *Sapria himalayana*.

Its purpose is educational: applying assembly, QC, annotation, or comparative
genomics skills learned during RE-SAPRIA to less extreme or otherwise
informative genomes.

Results stored here are not evidence for the RE-SAPRIA manuscript and should
not be used to support *Sapria* conclusions unless a future comparative analysis
is explicitly designed, documented, and incorporated into a new project phase.

Substantial future projects involving other species should preferably receive
their own repository rather than expanding this training directory indefinitely.
