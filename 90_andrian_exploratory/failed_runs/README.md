# Failed Runs

**Status: PRESERVED TROUBLESHOOTING ARCHIVE**

Failed, incomplete, resource-limited, or otherwise unusable computational runs
may be documented here when they provide a useful technical lesson.

A failed run can still record important information about:

- unsuitable parameters;
- software limitations;
- memory or runtime requirements;
- input-format problems;
- workflow assumptions;
- or features of an unusually difficult genome.

Where a failed run is documented, record:

1. research or technical question;
2. input dataset;
3. software and version;
4. exact parameters;
5. observed failure;
6. likely cause;
7. troubleshooting attempted;
8. lesson learned.

Failed outputs are not evidence for the manuscript and must remain clearly
separated from the frozen RE-SAPRIA analysis.
