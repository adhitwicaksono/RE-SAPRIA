# Parameter Tests

**Status: CLOSED / TRAINING ARCHIVE**

This directory records exploratory tests of software parameters, assembly
settings, QC strategies, or other methodological choices used for training.

Parameter tests are useful for understanding method sensitivity, but a parameter
combination that produces a better-looking numerical metric is not automatically
a biologically better analysis.

The frozen RE-SAPRIA manuscript uses the standardized workflows documented in
Phases 0–7. Results in this directory should not be substituted for those
workflows unless formally reproduced and migrated into the main analysis.

No new parameter optimization is planned for the current manuscript.
