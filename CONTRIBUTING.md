# Contributing

RE-SAPRIA is currently an active research project.

## Contribution rules

1. Do not upload raw sequencing reads or full genome assemblies.
2. Record software versions and exact parameters.
3. Separate exploratory runs from manuscript-grade analyses.
4. Keep failed runs and troubleshooting notes when they are informative.
5. Do not describe assembly discordance as confirmed biological structural variation without supporting evidence.
6. Add new decisions to `DECISIONS.md`.
7. Update the relevant phase README after each completed checkpoint.

## Authorship

Repository participation does not automatically establish manuscript authorship. Authorship will be based on documented intellectual and analytical contributions.
