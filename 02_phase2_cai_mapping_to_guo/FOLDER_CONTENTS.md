# Phase 2 folder contents

This upload package populates the Phase 2 subdirectories with compact provenance and frozen summary files.

- `ont_mapping/` — Cai ONT support for Guo
- `illumina_mapping/` — Cai Illumina support for Guo
- `coverage/` — canonical support/callability interval definitions
- `small_variants/` — strict Cai-versus-Guo small-variant summary
- `structural_variants/` — Sniffles2 structural-discrepancy summary
- `cai_fixed_on_guo/` — Cai-fixed pseudogenome rationale and QC
- `failed_guo_reassembly/` — provenance for the unsuccessful Guo Flye branch

Large BAM, VCF, BED, and FASTA datasets should be deposited in archival storage (for example Zenodo) and linked from the relevant README rather than committed directly to GitHub.
