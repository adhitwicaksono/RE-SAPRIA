# BRAKER3 standardized annotation panel

This directory documents the four softmasked BRAKER3 annotations used in the Phase 5 comparison.

| Representation | Genes | Transcripts | CDS features |
|---|---:|---:|---:|
| Guo published | 29,792 | 34,471 | 176,045 |
| Cai fixed-on-Guo | 29,887 | 34,783 | 187,772 |
| Cai min1250 | 20,149 | 24,733 | 138,398 |
| Cai Flye–HyPo | 19,430 | 23,822 | 132,227 |

The same three Guo paired-end RNA-seq libraries were mapped independently to each genome representation for the standardized project workflow. No protein evidence was used.

Raw GFF3 files are archived externally (planned: Zenodo). GitHub retains summaries, figures, scripts, and checksums.

See the parent [`README.md`](../README.md) and [`../tables/phase5_braker_summary.tsv`](../tables/phase5_braker_summary.tsv).
