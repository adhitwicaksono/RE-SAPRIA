# Phase 5 annotation comparison

This directory is for compact comparisons among the standardized annotation tracks.

Current Phase 5A conclusions:

- Guo and Cai fixed-on-Guo are nearly identical in global gene/transcript count.
- Cai min1250 and Cai Flye–HyPo differ strongly in assembly span but only modestly in BRAKER annotation count.
- Cai Flye–HyPo has the highest start+stop structural-completeness proxy.
- Long-intron burden is stable across all four BRAKER annotations.
- standalone AUGUSTUS is highly sensitive to masking state.

The next comparison layer will add RepeatMasker overlap and evidence-based confidence sets.
