# 99_education — RE-SAPRIA untuk Semua 🌺🧬

Folder ini menerjemahkan hasil RE-SAPRIA ke beberapa tingkat pembaca.

Tujuannya sederhana: **membuat genomik ekstrem *Sapria himalayana* terasa menakjubkan tanpa mengorbankan ketepatan ilmiah.**

## Versi data

Materi ini menggunakan hasil yang **sudah tersedia di repository sampai Phase 3**, termasuk:

- perbandingan assembly Cai dan Guo;
- reassembly Cai Flye–HyPo;
- pemetaan reads Cai ke Guo;
- perbandingan BUSCO;
- perbandingan RNA-seq;
- kontrol Cai fixed-on-Guo.

Phase 4 (repeat annotation) dan Phase 5 (gene annotation) masih berkembang. Karena itu, materi pendidikan ini **akan diperbarui lagi** ketika analisis repeat dan anotasi selesai.

## Satu kalimat inti

> **Pada satu spesies tumbuhan yang sama, kita bisa memperoleh representasi genom yang berbeda lebih dari 1 miliar pasangan basa—tetapi banyak bagian biologinya masih dikenali sebagai hal yang sama.**

Itulah teka-teki RE-SAPRIA.
