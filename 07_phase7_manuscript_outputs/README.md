# Phase 7 — Manuscript Outputs

## Objective

Freeze the methods, figures, tables, and supplementary files that enter the manuscript.

## Contents

- manuscript-ready figures;
- final tables;
- supplementary datasets;
- methods snapshots;
- software and database versions;
- accession lists;
- final assembly-selection rationale;
- reproducibility checklist.

## Freeze rule

Every manuscript figure and table must be traceable to:

1. a phase;
2. an input assembly version;
3. an exact command or Galaxy invocation;
4. a software version;
5. a small source table stored in this repository.
