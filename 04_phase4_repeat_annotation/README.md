# Phase 4 — Repeat Annotation

## Objective

Build and apply a harmonized repeat-annotation workflow to final Cai and Guo assemblies.

## Proposed workflow

1. RepeatModeler for each assembly;
2. curated or merged repeat-library decision;
3. RepeatMasker with identical settings;
4. repeat-class summary;
5. repeat-landscape analysis;
6. comparison of repeat composition;
7. characterization of unaligned Cai- or Guo-specific sequence.

## Key questions

- How much of the assembly-size difference is repeat-derived?
- Are Guo-only sequences enriched for particular repeat classes?
- Are polishing or assembly differences associated with repeat collapse?
- Do suspicious gene predictions overlap repeats?

## Warning

Flye's repeat-graph labels are not substitutes for RepeatMasker-derived genomic repeat annotation.
